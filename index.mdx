A Routa é uma plataforma para desenvolvedores que torna a comunicação com clientes simples de integrar e confiável de operar. O primeiro produto, o **Routa Messaging**, oferece uma API única para enviar e receber mensagens de WhatsApp, sem expor você a autenticação do provedor, webhooks, templates, limites de taxa, retentativas ou payloads específicos de cada fornecedor.

<Note>
  Envie sua primeira mensagem de WhatsApp em menos de 30 segundos. Siga o [Início rápido](/quickstart).
</Note>

```ts
import { Routa } from '@routa-chat/sdk'

const routa = new Routa({ apiKey: process.env.ROUTA_API_KEY! })

await routa.messages.send({
  channel: 'chan_...',
  to: '+5581999999999',
  text: 'Olá! Seu pedido foi confirmado.',
})
```

## Como a Routa funciona

A Routa fica entre a sua aplicação e o provedor de mensageria. O provedor é um detalhe interno: a API pública nunca expõe seus payloads nem seus códigos de erro.

```text
Sua aplicação  ──►  API da Routa  ──►  Provedor (WhatsApp Cloud API)  ──►  WhatsApp  ──►  Cliente final
      ▲                  │
      └── webhooks ◄─────┘   eventos normalizados: message.sent, message.delivered, message.read…
```

Duas ideias orientam o desenho da API:

- **Aceitar não é entregar.** `POST /v1/messages` responde `202 Accepted` quando a mensagem foi gravada de forma durável. A entrega é assíncrona e você acompanha cada etapa por [webhooks](/webhooks/overview) ou por `GET /v1/events`.
- **Nada se perde em silêncio.** A Routa absorve limites de taxa, filas, falhas do provedor e retentativas. Falhas permanentes viram eventos observáveis.

## O que a Routa não é

A Routa é infraestrutura. Não é um CRM, uma agência, um construtor de chatbots, uma plataforma de marketing nem um simples *wrapper* de provedor. Produtos da MultiON, incluindo o CRM, consomem os mesmos contratos públicos que qualquer outro cliente.
