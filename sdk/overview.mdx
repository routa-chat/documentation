O `@routa-chat/sdk` é o SDK oficial da Routa para Node.js. Ele oferece um cliente tipado para enviar mensagens de WhatsApp, submeter templates e receber eventos de entrega, com retentativas, idempotência e verificação de webhooks incluídas. A versão atual é a **0.3.0**. Se você vem da 0.2.0, veja [Atualizar para a 0.3.0](/sdk/upgrading).

## Requisitos

Node.js **22 ou superior** (`engines.node` é `>=22`). O pacote publica as versões ESM e CommonJS, então funciona com `import` e com `require`.



## Primeiro envio

```ts
import { Routa } from '@routa-chat/sdk'

const routa = new Routa({ apiKey: process.env['ROUTA_API_KEY']! })

const message = await routa.messages.send({
  channel: 'chan_...', // um canal conectado no painel da Routa
  to: '+5581999999999', // destinatário em E.164; o + inicial é opcional
  text: 'Olá! Seu pedido foi confirmado.',
})

console.log(message.id, message.status) // "msg_...", "accepted"
```

`status: 'accepted'` significa que a Routa recebeu a mensagem, **não** que ela chegou ao destinatário. A entrega é assíncrona: a mensagem avança por `sent`, `delivered` e `read` (ou `failed`), e você acompanha cada etapa por [webhooks](/sdk/webhooks) ou por `routa.events.list()`.

Para enviar um template aprovado no lugar de texto livre, passe `template` em vez de `text`:

```ts
await routa.messages.send({
  channel: 'chan_...',
  to: '+5581999999999',
  template: { id: 'tmpl_...', bodyParameters: ['Ana', '#1234'] },
})
```

`text` e `template` são mutuamente exclusivos: passar os dois é um erro de compilação.

## Autenticação

O cliente envia a chave como `Authorization: Bearer <chave>`. Crie chaves no painel, na página **Chaves de API** (no painel, **API keys**, no grupo **Developer** do menu lateral). O SDK **não lê variáveis de ambiente por conta própria**: passe o valor explicitamente.

```ts
import { Routa } from '@routa-chat/sdk'

const apiKey = process.env['ROUTA_API_KEY']
if (!apiKey) {
  throw new Error('ROUTA_API_KEY is not set')
}

const routa = new Routa({ apiKey })
```

`new Routa('rt_live_...')` é um atalho para `new Routa({ apiKey: 'rt_live_...' })`. Uma chave vazia lança um erro imediatamente, na construção, e não na primeira requisição. Uma chave de parceiro (`rt_partner_...`) também é recusada na construção: use o [`RoutaPartner`](/sdk/partner) com ela.

Para verificar uma chave sem efeitos colaterais, chame `routa.whoami()`:

```ts
const { organizationId, projectId, scopes } = await routa.whoami()
```

Veja mais em [Chaves de API](/authentication).

## Recursos do cliente

| Namespace | Operações |
| --- | --- |
| `routa.messages` | `send`, `retrieve`, `list`, `markRead`. Veja [Mensagens](/sdk/messages). |
| `routa.webhooks` | `create`, `list`, `retrieve`, `update`, `enable`, `disable`, `rotateSecret`, `constructEvent` e `deliveries`. Veja [Webhooks](/sdk/webhooks). |
| `routa.events` | `list`. Veja [Eventos, templates, mídia e uso](/sdk/resources). |
| `routa.templates` | `submit`, `uploadMedia`, `retrieve`, `list`. Veja [Templates](/sdk/templates). |
| `routa.media` | `upload`, `retrieve`. Veja [Mídia](/sdk/media). |
| `routa.usage` | `retrieve`. |
| `routa.whoami()` | Identidade da chave. |

A [API de parceiros](/partners/overview) tem um cliente separado, `RoutaPartner`, em `@routa-chat/sdk/partner`. Ele é **experimental**. Veja [Parceiros](/sdk/partner).

## Ainda não suportado

Conheça estas lacunas antes de construir sobre o SDK:

- **Enviar mídia, localização ou reações.** `messages.send()` aceita apenas `text` e `template`. Você pode [enviar um arquivo com `media.upload()`](/sdk/media) e guardar o `id`, mas nenhuma mensagem consegue referenciá-lo ainda. Mensagens recebidas e históricas desses tipos podem ser lidas, mas não enviadas.
- **Editar, excluir ou sincronizar templates.** O SDK submete, consulta e lista templates. Alterar ou remover um template só é possível no painel: a API não oferece essas operações a uma chave de API.
- **Canais.** Não existe o namespace `routa.channels`. Conecte e gerencie canais no painel e passe o id do canal para `send()`. Quem usa a [API de parceiros](/sdk/partner) lista e exclui canais desativados com `partner.channels`.
