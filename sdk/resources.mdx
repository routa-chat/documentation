## Eventos

`routa.events.list()` lista o log de eventos normalizados. É o caminho de reconciliação depois de uma indisponibilidade do seu servidor. Veja [Reconciliar eventos](/webhooks/reconciliation).

```ts
for await (const event of routa.events.list({ type: 'message.failed', after: lastEventId })) {
  console.log(event.type, event.data)
}
```

| Parâmetro | Descrição |
| --- | --- |
| `type` | Filtra por um tipo de evento. |
| `after` | Retoma depois deste id de evento. |
| `limit` | Itens por página, de 1 a 100. |

Cada item é um `RoutaEvent`, o mesmo tipo que `webhooks.constructEvent()` retorna: `id`, `type`, `apiVersion`, `schemaVersion`, `projectId`, `externalRef`, `sequence`, `occurredAt`, `recordedAt` e `data`.

`externalRef` é o `external_ref` do projeto, ou `null` quando o projeto não tem um. Só projetos criados por um [parceiro](/partners/overview) têm esse valor.

O SDK conhece 17 tipos de evento. Veja a lista em [Webhooks](/sdk/webhooks#tipos-de-evento).

## Templates

`routa.templates` submete templates para aprovação, envia o arquivo de um cabeçalho de mídia e consulta o resultado. Veja [Templates](/sdk/templates) para os componentes e os erros, e [Templates](/concepts/templates) para o ciclo de vida.

```ts
const template = await routa.templates.submit({
  channel: 'chan_...',
  name: 'confirmacao_pedido',
  language: 'pt_BR',
  category: 'utility',
  bodyText: 'Olá {{1}}! Seu pedido {{2}} foi confirmado.',
})

console.log(template.id, template.status) // "tmpl_...", "submitted"
```

| Método | Descrição |
| --- | --- |
| `submit(params)` | Cria o template e o envia para aprovação. Aceita `components`. |
| `uploadMedia({ file, contentType })` | Envia o arquivo de um cabeçalho de imagem, vídeo ou documento. |
| `retrieve(id)` | Consulta um template e o status de aprovação. |
| `list({ channel?, limit?, cursor? })` | Lista templates, com paginação automática. |

```ts
import { toTemplateId } from '@routa-chat/sdk'

const template = await routa.templates.retrieve(toTemplateId('tmpl_...'))

switch (template.status) {
  case 'approved':
    // já pode ser enviado
    break
  case 'rejected':
    console.log(template.rejectionReason)
    break
  case 'failed':
    console.error(template.failureCode, template.failureDetail)
    break
}
```

O SDK **não edita nem exclui** templates. Essas operações existem só no painel. Um template com `deletionRequested: true` está sendo excluído e não pode ser enviado.

## Mídia

`routa.media` envia um arquivo para a Routa e consulta o objeto de mídia. Veja [Mídia](/sdk/media) para o envio e [Mídia](/concepts/media) para o conceito.

```ts
import { toMediaId } from '@routa-chat/sdk'

const media = await routa.media.retrieve(toMediaId('med_...'))

if (media.status === 'ready' && media.url) {
  const file = await fetch(media.url)
}
```

`retrieve()` devolve uma URL assinada nova, válida por 15 minutos, quando o status é `ready`.

## Uso

`routa.usage.retrieve()` devolve o uso medido do projeto em um período de até 92 dias. Veja [Uso](/billing/usage).

```ts
const usage = await routa.usage.retrieve({ from: '2026-09-01', to: '2026-10-01' })

for (const record of usage.data) {
  console.log(record.metric, record.channelType, record.quantity, record.unit)
}
```

`from` é inclusivo e `to` é exclusivo, em datas UTC `YYYY-MM-DD`.

## Identidade da chave

`routa.whoami()` resolve a chave de API em uso, sem efeitos colaterais:

```ts
const { organizationId, projectId, apiKeyId, scopes } = await routa.whoami()
```

`scopes` é uma lista de `ApiKeyScope`: `messages:read`, `messages:write`, `channels:read`, `channels:write`, `events:read`, `webhooks:write`, `usage:read`, `templates:read`, `templates:write`, `media:read` e `media:write`.
